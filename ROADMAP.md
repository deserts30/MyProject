# RobloxProject — Roadmap

Дорожная карта разработки игры. Каждая задача связана с GitHub Issue.

## Обозначения

- `[ ]` — не начата
- `[~]` — построена и протестирована в Studio, ожидает подтверждения
- `[x]` — построена, протестирована и одобрена (дата одобрения)

## Как работать с этим файлом

1. **Создание новой задачи**: `roblox-to-issues` создаст GitHub issue и добавит строку сюда
2. **Построили и протестировали**: поменяйте `[ ]` на `[~]`
3. **Одобрили**: поменяйте `[~]` на `[x]` и добавьте дату

**Помните:** Код Luau живет в облаке Roblox, а не в Git. Этот файл — только для планирования.
